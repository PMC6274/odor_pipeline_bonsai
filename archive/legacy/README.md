# Legacy reference archive

These files were moved out of the active project during the consolidation onto
`3device_parallel_64mix.bonsai`. Nothing here is needed for normal operation.
Use the root `start_experiment.bat` and the current `experiments/` folder.

The older workflows retain a complete copy of their Bonsai helper workflows in
`Extensions/`. The old single-odor/debug generators produce different payload
formats, and the older mixture scripts produce seven values instead of eight.
Their TXT files must not be selected for the active 64-mix workflow.

YAML paths and batch files are preserved as historical references. Their original
root-relative paths and assumptions may no longer resolve from this archive.
Restore or adapt them deliberately before reuse. `README.original.md` records
the documentation before consolidation.
